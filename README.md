# ЛР2. Мультимодальный краткосрочный прогноз провалов спроса в метро

Дисциплина «Прикладные задачи машинного обучения». Лабораторная работа 2.

**Тема ВКР:** «Разработка модели динамического прогнозирования спроса на городской транспорт
с учётом пространственных и временных зависимостей».

**Задача.** Каждый час (06:00–23:00) для каждой станции метро Нью-Йорка предсказать, будет ли в
ближайший час провал спроса: входов меньше 75% обычного уровня. Используются три модальности:

| Модальность | Что это |
| --- | --- |
| числа | история входов станции и соседей, календарь, погода |
| текст | служебные оповещения MTA, активные на момент прогноза |
| изображение | график входов за 48 ч на фоне той же недели неделю назад |

Сравниваются 3 одномодальных baseline'а и 8 мультимодальных моделей и схем слияния: раннее, позднее,
gated, cross-attention, 3 VLM без дообучения. Вклад каждой модальности проверяется абляциями,
бутстрэпом и permutation test. Подробности — в [`PROTOCOL.md`](PROTOCOL.md).

## Структура

```
PROTOCOL.md          протокол (зафиксирован до запуска моделей) и журнал отступлений
labkit.py            общий код: синхронизация S1–S10, объекты, модальности, метрики, статистика
notebooks/           ноутбуки для Kaggle (собираются из notebooks/src/*.py)
notebooks/src/       исходники ноутбуков и сборщик build_notebooks.py
results/             выводы ноутбуков, скачанные с Kaggle (по папке на ноутбук)
report/              обзор литературы, отчёт
```

## Данные

1. **`vkr-transit-lab`** (приватный Kaggle-датасет из ЛР1, версия v1): почасовые входы по 424 станциям,
   ковариаты, граф станций. Подготовлены в рамках ВКР (`vkr-transit`).
2. **`vkr-mta-alerts`** (новый приватный Kaggle-датасет): 45 файлов `alerts_YYYY-MM.parquet` — служебные
   оповещения MTA по метро за 01.2023–08.2026. Источник: [data.ny.gov `7kct-peq7`](https://data.ny.gov/d/7kct-peq7).
   Скачаны скриптом `src/download_alerts.py` из репозитория ВКР.

## Как повторить на Kaggle

Каждый ноутбук: **File → Import Notebook** → загрузить `.ipynb` → справа **Add Input** → **Save Version**
(**Save & Run All**). Затем скачать **Output** в `results/<имя ноутбука>/`.

| № | Ноутбук | Accelerator | Internet | Inputs | Время |
| --- | --- | --- | --- | --- | --- |
| 1 | `lab_00_data` | нет | нет | `vkr-transit-lab`, `vkr-mta-alerts` | ~5 мин |
| 2 | `lab_01_embed` | GPU T4 | да | `vkr-transit-lab`, вывод `lab-00-data` | ~40 мин |
| 3 | `lab_02_gbm` | нет | нет | `vkr-transit-lab`, `vkr-mta-alerts`, выводы `lab-00-data`, `lab-01-embed` | ~1 ч |
| 4 | `lab_03_neural` | GPU T4 | нет | выводы `lab-00-data`, `lab-01-embed`, `lab-02-gbm` | ~40 мин |
| 5 | `lab_04_vlm_qwen3b` | GPU T4 | да | `vkr-transit-lab`, вывод `lab-00-data` | ~1 ч |
| 6 | `lab_04_vlm_qwen7b` | GPU T4 | да | то же | ~2 ч |
| 7 | `lab_04_vlm_internvl` | GPU T4 | да | то же | ~45 мин |
| 8 | `lab_05_summary` | нет | нет | `vkr-transit-lab` + выводы **всех** ноутбуков выше | ~10 мин |

Ноутбуки 5–7 не зависят от 2–4 и могут идти параллельно с ними.
